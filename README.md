# pierrickrauby.io

Personal portfolio website for Pierrick Rauby. React single-page application deployed to GitHub Pages.

## Branch Structure

- **`main`**: React source code — development happens here
- **`gh-pages`**: Built/deployed static files generated by `npm run deploy` — do not edit directly

## Development

```bash
npm install        # Install dependencies
npm start          # Dev server at http://localhost:3000
npm run build      # Production build to /build directory
npm test           # Jest test runner (interactive watch mode)
npm run deploy     # Build + deploy to gh-pages branch
```

## Tech Stack

- React (Create React App)
- Bootstrap 5 + Material UI
- react-router-dom v7 with hash-link navigation
- tsparticles for interactive background
- react-vertical-timeline-component for experience/education
- FontAwesome 6 for icons

## Content

Resume content is driven by `public/resume.json`. Edit that file to update experience, education, skills, and social links. Projects in `src/components/Projects.js` are hardcoded.
